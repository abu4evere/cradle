# C2-K3: whom to copy when skills build on each other, with the memory brain (DRAFT, 14 November 2026)

**Why:** C2-K hit the floor, and C2-K2's difficulty check found no learnable level. Mind Lab WS then showed two things:
- the floor was partly C2-K's design (gated copying, a non-expert half the time);
- **a learned memory of the showing** gives deferred imitation (0.91 against 0.43) and fast skill once teaching stops.

The creator agreed to return to C2-K's question with that brain.

## What changes from C2-K
1. **The child's brain is WS's Bm:**
   - a learned recurrent state;
   - the showing is fed as steps just before the try and is not in view during it;
   - all shown lids are copied before the try (WS), at rate 0.5 × w.
2. **G against U** now differs only in the child's own tries:
   - **G:** a wrong lid ends the try;
   - **U:** every lid is tried.

   A demonstration still stops at the demonstrator's first wrong lid, so a bad first step also hides the later lids.
3. **The difficulty level is chosen first** (as C2-K2: pilot seeds 1001–1024, only Cb and T):
   - **levels, hardest first:** K1, 3 lids, 3 tries per kind per day; K2, 2 lids, 3 tries;
   - **the rule:** the first level with Cb's G day-30 full-box success in [0.15, 0.60] and T below 0.85 in both
     conditions;
   - otherwise, stop.
